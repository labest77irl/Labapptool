# Labapptool Serial Port/ UDP Terminal/Test tool.

1. A simple Сom Serial / UDP Terminal with the ability to save logs, command macros and test commands.
2. Custom Serial Port baud rates. *Not guaranteed, depends on OS and driver. Usually works with USB-COM adapters.
3. Possibility of load previously recorded settings macros for different setups.
4. Logs can be saved in Plain Text / HTML formats.
5. Basic UDP Server / Client.
6. Transferring a binary file via a COM port or UDP, either in full or in parts (chunks), with a specified delay.
7. Written in QT 6 using native C++ for OS native-speed/resource execution.
8. No hidden manipulation of com port pins  (i.e. CTS/RTS).
9. Available for Windows x64(portable), Linux x86-64(.deb install package/Appimage), Linux aarch64(arm v8) (.deb install package/ Appimage). (see releases).
